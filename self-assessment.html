Tech I work with

  • Frontend: React, Next.js, TypeScript, Tailwind CSS
  • Mobile: Swift, SwiftUI (iOS)
  • Data: PostgreSQL, MongoDB, Supabase — schema design, JPA/Hibernate, RLS
  • Infrastructure: Docker, GitHub Actions CI, Vercel, Render, Railway
  • AI: LangChain, OpenAI & Anthropic APIs, streaming SSE, agent workflows

Projects on this site

Forge is a multi-agent AI workflow platform with a visual blueprint editor and cross-platform computer use. LastGate is a pre-flight commit guardian for AI-generated code. NexaBase is a deployable AI SaaS starter with auth, billing, and streaming chat. Anomaly visualizes any codebase as a force graph. RepoRadar scans GitHub profiles. TaskFlow is a Spring Boot + React task manager with Kafka pipelines. a+ Terminal is a privacy-first iOS SSH client.
